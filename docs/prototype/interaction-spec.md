## 状态检查脚本（给02/03/05/07/08）

1. 默认标准输入新建，0→1→2→3→4，对应init/probe/move-left/probe/found；left从0到3，mid在更新后清空，result=3，按lineId高亮。
2. 回看第2步并提问，再前进；旧反馈必须仍标原第2步。编辑输入立即停止播放，旧面板明确未使用新值。
3. 空数组新建：right=-1，只有init/not-found；重复数组目标3命中任一匹配，不能声明首个；目标4显示未找到。
4. 无序、非法JSON、小数、超过100项或不安全整数：保留输入并提示，不排序。演示请求失败不替换旧run；取消模拟后重试。
5. Agent未配置：提供知识/固定练习入口，不能显示虚构token或成功引用；知识加载失败提示使用预览服务。
6. 空记录进入练习，错答7产生错题，刷新仍在；切换三级提示可看到解析；取消清除无变化，确认后为空。存储禁用时告知只在内存，不能声称持久化成功。

生产还需补做：真实API网络错误、服务端run过期、真实模型超时/预算、题目版本变更等，见需求第8节。原型仅模拟请求失败和固定503，不声称已对生产异常完成验证。

## 桌面与手机布局

桌面以左导航固定，主区域按输入→动画/代码与右侧辅导排列，变量置动画下方；代码显示13行c-v1片段。动画数组可局部横滚容纳100项。颜色外使用L/R/M标签、零起始下标和事件文本；焦点轮廓可见，输入具有label、状态使用role=status。

宽度1100px以下辅导放到代码下方；650px以下导航变横向，目录与知识单列，工作台依次输入→动画/变量/控制→代码→辅导；数组局部横滚而非整页横滚。手机只定义基本浏览及按钮操作，不要求03另做完整移动动画产品。账号/跨设备/后台/自由拖拽均无可执行入口，标扩展预留。
