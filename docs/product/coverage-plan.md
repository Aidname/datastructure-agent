## 八组重点动画的验收入口

| 动画组 | 计划轨迹/视觉重点 | 需提供的独立边界预期 |
|---|---|---|
| 二分查找 | 闭区间与代码变量联动 | 空、单元素、重复、负数、未找到；04已有，08仍需交叉验收 |
| 链表插入删除 | 前驱、后继与链接变更 | 空表、头尾、单节点、非法位置 |
| 二叉树遍历 | 当前节点、辅助栈/队列、访问序列 | 空树、单节点、偏斜树 |
| BFS / DFS | 已访问集合与前沿 | 断开图、环、遍历起点/邻接顺序 |
| 快速排序 | 枢轴、分区与递归范围 | 空、全相等、已排序、逆序 |
| 归并排序 | 拆分、比较、归并指针 | 奇数长度、重复、稳定性说明 |
| KMP | i/j、next/nextval与跳转 | 空模式策略、失配、重叠匹配 |
| 最短路径 Dijkstra / Floyd | Dijkstra松弛/已确定集合；Floyd中间点k与距离矩阵 | 不可达、零权；Dijkstra拒负权，Floyd负环策略待04/06确认 |

除二分外是正式版计划，不在本次开发实现。八组中最短路径明确含两个算法，BFS/DFS也分开核对；不能把分组数当算法总数。
