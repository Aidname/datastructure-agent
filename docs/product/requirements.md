## 2. 介绍、用户与真实调研依据

产品帮助学习者联系代码、变量、执行过程、解释和练习。目标用户是初学数据结构的学生、进行408复习的学生；教师/助教可在课堂解释边界变化。核心任务是观察一步、解释原因、预测下一步、复盘错误。

设计假设：学生可能混淆下标与值、闭区间与半开区间、不理解边界为何越过mid。此为课程任务和自编题目导出的假设，**尚无真实访谈结论**；由07试用验证，不能据此声称学习效率提升。

调研补入规则：每项结论关联匿名证据编号和需求ID；保留不支持假设的观察；记录因此修改的设计和版本。无材料保持待补，不杜撰人数、语录或统计。

术语：run为一次固定输入运行；step为不可变步骤快照；stepIndex从0开始；lineId为稳定源码标识；original为项目自编；available仅表示内容可供接入；planned不是验收通过。

## 4. 用户场景与流程

| 场景 | 前置/触发 | 主流程 | 异常/退出 |
|---|---|---|---|
| S01 初学观察 | 目录选二分 | 有序条件→输入→新run→前进/回看→解释边界 | 无序原地改正，不偷偷排序 |
| S02 暂停提问 | 停在实际step | 锁定runId/stepIndex→提问→取状态/知识→带引用答复 | 模型不可用仍可看轨迹、做固定题 |
| S03 预测练习 | 从工作台进题目 | 阅读独立context→作答→程序判分→提示→重试 | 题目context不冒充实时step |
| S04 复盘错误 | 本机有记录 | 看错题/版本/当时情境→再练→保留新结果 | run过期重建；空记录给练习入口 |

修改输入暂停播放并标记“创建新运行后生效”；旧run仍可回看，不套用新输入。新run建立后清除旧计时器、隔离旧响应，全部面板到第0步。重置仅回当前run第0步，不重新计算。

## 6. 数据关系和接口

见[领域模型](../architecture/diagrams/domain-model.svg)。Run组合多个Step，Card关联SourceReference，Exercise产生AnswerRecord，LearningRecord汇总作答/情境；Agent通过状态服务和检索工具取依据，不能改写轨迹。分析模型不要求JS重写为class。

| 对象 | 现有字段或设计信息 | 边界 |
|---|---|---|
| AlgorithmRun | runId、createdAt毫秒、algorithm、sourceVersion、sourceLines、steps、result | 顶层无array/target，从step读取；服务内存保留1小时、每60秒清理、重启丢失；容量上限待04/01 |
| Step | schemaVersion、algorithm、stepIndex、event、sourceVersion、lineId、array、target、variables、done、result | 六事件init/probe/move-left/move-right/found/not-found；更新mid=null；独立快照 |
| Card/SourceReference | id/topicId/content/keywords/version/sourceId/sourceType/verified；引用cardId/sourceId/chapter/pages | original可空chapter/pages；verified不等于教材验收 |
| Exercise | id/version/topicId/type/prompt/context/options | context可before-probe、sourceVersion=null，不是引擎step |
| AnswerRecord（设计） | exerciseId、exerciseVersion、answer、correct、hintLevel、answeredAt、contextSnapshot；可选runId/stepIndex | 07实现；当前判分API不保存、不校验exerciseVersion |
| LearningRecord（设计） | 本机记录版本、主题、作答/错题、最后情境 | 不保存密钥；清除确认；run过期用快照回顾或重新创建 |

路径及成功/错误字段沿用API契约。创建/判分请求体最多10240 UTF-8字节；非递减安全整数数组最多100项，target安全整数；允许空、负数、重复值，命中不保证首/末，未找到-1。GET题目当前忽略topicId，不承诺已筛选。过期run为404 RUN_NOT_FOUND；步骤越界400 STEP_OUT_OF_RANGE，非法路径可能404 NOT_FOUND。前端不得推断不存在的字段。

## 7. Agent知识、工具与流程

正式主要资料规划为《王道数据结构2027》并复核官方大纲。本批二分获准自编，标sourceType=original；未核验教材页码/草稿不能伪装可信来源。

规划流程：接收`{runId,stepIndex,question,hintLevel}`→校验→只读状态工具取04真实step→知识检索取06已检查卡→观察/规则/完整解释三级辅导→答复附stepRefs/sourceRefs→记录真实usage、耗时及工具调用。来源缺失明确说明；run不存在提示重建。不接受客户端自报variables替代权威状态，引用必须在工具返回集合中；切换步骤后旧答案保留原标签。

算法由程序生成，客观题由程序判分，模型只辅导。计划后端可配置DeepSeek API适配器，密钥只在后端；当前未完成provider/SDK集成。预算总上限30元，05落实调用前余额/账单核验、用量记录及停止策略；缺token数据记unknown，价格/账单另核。MODEL_TIMEOUT/504、MODEL_UNAVAILABLE/502、BUDGET_LIMIT/429是计划，当前只有固定MODEL_NOT_CONFIGURED/503，不声称已实测。

## 8. 异常、状态与恢复

| 状态 | 页面行为/恢复 | 验收预期 |
|---|---|---|
| 创建加载 | 按钮禁用、显示创建中，旧播放暂停 | 无重复创建，成功到第0步 |
| 输入非法/无序/超限 | 旁显错误并保留原文 | 修改可重试，不排序 |
| 空数组 | 空态、right=-1、mid未计算 | init→not-found，不访问元素 |
| 重复值 | 实际命中下标，说明非首末保证 | 重复数组返回有效匹配 |
| 未找到 | result=-1、搜索结束 | 回看正常，无过期mid |
| 请求失败/过期 | 重试或重新创建 | 不伪造run，不影响其他模块 |
| 知识501 | 未接检索；静态原型卡标来源 | 不冒充API已完成 |
| 模型503及计划失败 | 明确不可用，保留问题和步骤 | 固定题/回看仍可用 |
| 空记录/存储失败 | 练习入口/无法保留说明 | 无虚构时长、正确率 |
| 切换/旧请求 | 暂停旧播放、请求标识隔离 | 旧回答保留原上下文 |
| 清除记录 | 说明仅本机并确认 | 取消不变、确认后为空 |

## 9. 非功能要求

原生HTML/CSS/JS与Node.js；原型在docs独立预览，不覆盖生产入口。用L/R/M文字和状态说明辅助颜色；按钮有键盘焦点，变量null显示未计算；100项数组局部横滚。手机按输入→动画→代码→变量→辅导堆叠，仅承诺基本浏览设计，不扩大为完整移动开发。实际性能需08指定设备测量，暂不声称达标。

不采集账号，不提交密钥、私有访谈及整本教材；模型输出用文本呈现，不直接执行HTML。本机记录不承诺跨设备或永久保留，存储失败须提示。每页标本次样例设计/正式版规划/扩展预留，源文件和预览可追溯。
