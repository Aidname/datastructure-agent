# 成员 08：独立验收与定制效果对比

建议分支：`test/m08-acceptance-evaluation`。主责：`tests/`、`docs/evaluation/`。

## 具体任务

1. 用人工推演/已核验展示代码建立至少6类预期：普通命中、首尾命中、未找到、空数组、单元素、重复值。
2. 检查每步边界、中点、比较、行标识和结束结果；预期不能由被测JS引擎直接生成。
3. 检查输入重置、回看、暂停提问、刷新记录、JSON错误、run不存在、模型缺配置/超时。
4. 实际执行后补自动化测试或可重复操作脚本，记录输入、预期、实际、版本和证据；骨架检查不是业务验收。
5. 设计3个对比问题：正常步骤、边界解释、错误理解纠正；同模型同基本输入，定制组记录实际服务端状态/上一步、源码/高亮、历史与提示词，固定提示和配置并记录差异。
6. 用准确性、状态一致性、步骤归属可核验性、提示有效性逐项评价；保留真实输出，不预设提升、不挑掉失败。
7. 20日前给01缺陷清单和结论，给10可用于PPT的真实证据。

## 验收

复测步骤可复现；3个真实前后结果及核验存在；没有用协议样例替代模型实验；未完成项明确列出。
