# 成员 05：Agent、工具与聊天

2026-10-23：模型适配与聊天已接入。按用户调整，步骤聊天不再调用知识检索或展示知识卡出处，而是直接带服务端当前/上一步、源码/高亮及最多10轮历史；下文冲突的聊天检索/资料引用要求已取消，独立知识查询继续保留。真实效果证据仍待05/08补齐，详见[当前状态](../../architecture/current-status.md)。

建议分支：`feat/m05-agent`。主责：`backend/src/agent/`、`backend/src/knowledge/`、`frontend/src/features/agent/`。公共server入口由04整合。

## 具体实现

1. 实现可配置DeepSeek适配器；密钥只在后端；配置缺失返回MODEL_NOT_CONFIGURED，不伪装成功。
2. 实现getCurrentStep(runId,stepIndex)与retrieveKnowledge(question,topicId)工具；状态来自04，知识只采用06已核验卡片。
3. Agent结合工具结果回答当前步骤问题，返回所用step引用和资料出处。处理与当前算法无关的问题和信息不足。
4. 三级提示递进；先观察，再规则，再完整解释。说明当前提示级别，不把教材出处交给模型猜。
5. 实现聊天输入、发送/加载/失败/重试、当前步骤标签；提问期间切换步骤时，答案仍标注它针对的原步骤。
6. 记录实际usage、调用次数、耗时和可用账单信息，按团队30元上限管理测试；未取得价格与账单核验时不声称金额精确。
7. 模型超时或失败不阻断动画、固定说明与题目；限制输出长度和请求频率，错误回显不暴露密钥。
