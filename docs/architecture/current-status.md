## 模型与资料口径

显式AGENT_MOCK=true优先走开发模板；关闭Mock且后端配置Key才调用DeepSeek；两者都没有时聊天返回503。知识卡、动画和程序判分不依赖模型。空模型回复/上游失败可重试，限流、预算和用量控制继续保留。

本批10卡10题允许项目自编，不要求教材具体章节/页码；不伪造出处。聊天兼容字段sourceRefs为空、knowledgeUsed=false、retrieval标disabled；独立知识查询仍有自身真实来源信息。后续真实引用教材时仍核验出处。
