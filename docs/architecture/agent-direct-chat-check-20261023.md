## 当前行为

- 有效问题在真实运行、参数与额度检查后直接调用配置的模型。不做关键词匹配、省略句分类、口语数值白名单或无关问题正则拦截；知识资料不可用不阻断聊天。
- 每次注入服务端当前数组/目标/事件/变量、上一步快照、完整展示代码sourceLines/sourceVersion及当前高亮lineId、最多10轮历史。模型不会自动看到整页HTML、其他未提供的界面内容。
- 模型可用通用算法知识解释，页面事实以服务端为准。历史仅是参考数据；当前状态优先。保留自然助教风格、三级解释深度，不伪造已核验资料或引用。
- 前端不显示聊天知识卡出处。兼容字段sourceRefs为空、knowledgeUsed=false、retrieval.method=none/status=disabled，stepRefs移除knowledgeCard。独立知识卡页与查询API保留。
- 每个成功完整问答都可进入历史，不再依赖knowledgeUsed；最多10轮/8000字符、1小时无活动过期、200会话上限与原有隔离/幂等不变。失败不写历史；空模型输出返回502可重试。
- 保留密钥后端存储、Mock/无Key模式、限流、预算预留、超时与错误处理。没有改变引擎、动画、题库、程序判分或页面布局。
- 删除已无消费者的step-question.js、省略追问正则及知识卡输出规则；独立知识检索的实现与测试仍保留。
