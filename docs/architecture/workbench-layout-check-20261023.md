## 当前界面

- 主框架采用09原型的紫色、浅色背景及原有标志；侧栏可收起为图标，偏好仅保存在本机独立布局键。导航连接现有工作台、知识卡、练习和记录，不新增课程目录等其他页面。
- 桌面源码栏330px，与占主要宽度的动画并排；四个变量在代码下方同排，支持“未计算”和安全整数长值。窄屏先动画后代码。
- 03数组、指针和转场继续消费04真实步骤；画布改白底，移除背景网格及其无用模块。固定图例位于缩放层外，避免窄屏因图例过宽把数组压小。
- 移除可见速度选择和右下步骤计数，播放默认1秒/步。底层播放器仍保留setSpeed能力。左侧保留重置、上一步、播放/暂停、下一步、末步；时间轴在右侧同排并占剩余宽度。标签按宽度/步数稀疏显示，当前步高亮，所有步骤仍可点击或按左右/Home/End选择。读屏保留步骤状态。
- 05步骤辅导移入右下悬浮窗口，可拖动、收起及重新打开；保留草稿、历史和进行中的请求。打开窗口不暂停，发送前暂停并提交原步骤上下文，晚到回答仍标注原步骤；换run仍取消过期请求。
- 浮窗保留思考提示、模型状态、问答、知识卡及练习入口。知识卡使用既有真实接口读取，并如实标注项目自编；请求失败可重试。悬浮球自动避开时间轴，全屏时辅导窗口及球隐藏。

未修改引擎、HTTP接口、题库、判分及本机学习记录格式。本轮不表示完成09原型全部页面，也不代替08独立验收及真实模型效果检查。
